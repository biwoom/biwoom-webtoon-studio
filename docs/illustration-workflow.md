# 일러스트 제작 워크플로 v0.1

## 범위와 공통 기반
같은 Studio 저장소 안에서 단일 이미지·연작 일러스트를 제작하는 별도 트랙입니다. 웹툰 설계 v1.2의 G0–G4나 기존 회차 데이터를 변경하지 않습니다. 출전/권리·참조 자산·불변 버전·해시·기술 QA·수정 이력·보관 원칙은 공유합니다. 10컷/EP01 스키마, 세로 연결, 말풍선, 회차 연속성 검사는 그대로 강제하지 않습니다. 홈페이지 접근·등록·배포는 범위 밖입니다.

## 이미지별 최소 계약
- IL 작품 ID, 이미지 ID, 버전, 목적/독자, 사용처와 비율·목표 픽셀·투명 배경 여부.
- 근거 출전·판본·구체 위치와 관찰한 사건, 각색한 연출, 넣지 않을 사건/도상.
- 권리 상태와 외부 서비스에 제공 가능한 자료. 공개된 페이지라는 사실만으로 표현·번역·삽화 재사용 권리를 승인하지 않습니다.
- 참조 이미지의 출처/권리/버전, 인물 비례·의상·화풍 유지 조건, 구도와 시선/손/소품 관계.
- 후보 실제 파일 SHA256, 생성 경로와 알려진 모델/시각/입력 요약. 알 수 없는 호출 ID·비용은 추정하지 않고 미기록/불명으로 남깁니다.
- 글자가 있다면 편집 가능한 별도 텍스트와 해시. 무문자 이미지는 텍스트 없음으로 명시합니다.

## 일러스트 승인 단계 (웹툰 게이트와 별개)
| 단계 | 검토 대상 | 기록 |
| --- | --- | --- |
| I0 | 장면·의미·출전/권리·용도 | brief와 제한 |
| I1 | 인물·미술 기준 및 구도안 | 참조/썸네일의 정확한 버전 |
| I2 | 후보 이미지와 수정점 | 기술 QA와 별도 인간 미술/교학 검토 |
| I3 | 최종 선택 이미지·선택적 문구·크롭·출력 규격 | 정확한 조합 해시, 실제 사용자 결정/주체/시각 |

사용자의 시험 수행 지시는 시안 제작·검수·비공개 보관을 진행하는 권한이지 아직 보지 않은 그림의 I3 승인이 아닙니다. 별도 승인 없이 후보·검토 패키지를 만들 수 있는 요청에서도 I0/I1의 미결정 사항은 제안으로 표시하고 소급 승인하지 않습니다. 모든 단계가 승인되었다고 자동 기록하지 않습니다. 그림/글자/크롭 변경은 관련 승인을 재검토하며 과거 기록을 덮어쓰지 않습니다.

## 실행 흐름과 실제 인계
1. Dot이 brief와 허용 범위를 작성하고 출전 사실/연출 해석을 구분합니다.
2. 구도·시선·소품만 보는 간단한 썸네일 또는 명시된 후보 계획을 만듭니다. 요청한 검토 방식에 맞춰 필요한 인간 결정을 받습니다.
3. 승인된 사용 범위에서 내장 이미지 도구 등으로 후보를 만듭니다. 별도 API 예산은 현재 없으므로 외부 유료 API를 호출하지 않습니다. 내장 생성이 로컬 자동 엔진으로 통합되었다고 주장하지 않습니다.
4. Dot→로컬 Codex 인계는 대상 파일/버전·기대 SHA256·허용 경로·검사·실패 조건을 명시합니다. 실행자가 실제 인수 결과와 해시/로그를 돌려주는 수동 지원 경로이며 인증된 자동 승인 bridge는 미구현입니다.
5. 이미지 형식·전체 디코딩·크기·해시·파일 누락을 기술 QA로 확인합니다. 원전 사건, 불교적 의미, 인물 비례, 손/팔 연결, 소품, 시선, 배경 밀도는 사람이 별도로 검토합니다. 기술 pass는 미술/교학/사용자 승인과 다릅니다.
6. 필요한 수정은 해당 영역과 보존 조건을 지정하고 새 v02 파일로 만듭니다. v01은 보존하며 수정 전후 및 부작용을 비교합니다. 반복 호출/재시도는 요청과 예산 범위 안에서만 수행합니다.
7. 정확한 후보를 사용자에게 제시합니다. I3 승인 전 파일은 후보·비공개 시험본으로 표기합니다. 승인된 최종본과 보관용 후보/미리보기는 별도 상태입니다.
8. PNG 원본, 필요 시 JPEG 미리보기/HTML 검토본/ZIP과 manifest를 로컬에 보존하고 실제 바이트·CRC를 재검증합니다. 글꼴·참조 자산 재배포 권리는 따로 확인합니다. 출력 저장은 공개 허가가 아닙니다.

## 프레이밍·검수 기준
캐릭터 시트의 머리/어깨/몸통/팔다리 비례를 패널에 맞추려고 줄이지 않습니다. 의미에 맞는 중경·상반신·얼굴/손 근경을 선택하고 크롭과 해부학적 압축을 구분합니다. 원경의 균일 축소·설명 가능한 원근 단축은 허용합니다. 불분명한 도상·가려진 손·권리 문제는 uncertain으로 남겨 판단을 요청합니다.

## 로컬 산출물과 구현 한계
작업별 새 `output/illustrations/IL-NNN/` 아래 brief, candidates/v01·v02, qa, review, exports를 역할에 맞게 사용합니다. 필요한 폴더만 만들며 기존 파일을 덮어쓰지 않습니다. 실제 이미지/원고·작업별 식별자는 공개 소스에 자동 포함하지 않습니다. 작업공간의 경로 검사와 Git 제외는 OS 보안 경계를 대체하지 않습니다.
현재 웹툰 validator는 EP01/10컷에 고정되어 이 계약을 검증하지 못합니다. 새 트랙은 문서화된 수동 인계·일반 래스터/해시 검사부터 검증하며, 일러스트 전용 스키마·실제 승인 인증·생성 공급자·완성본 coordinator는 향후 구현입니다. 파일럿 결과에는 실제 수행 단계/미수행/인간 판단 대기/실패를 구분합니다.

## 확정본의 공개 저장 경계
사용자가 공개 전송을 승인한 정확한 확정본만 `published/illustrations/IL-NNN/`에 원본 바이트를 유지하여 복사합니다. 해당 작품의 제목·간단한 설명·공개 출전 링크만 함께 둡니다. 후보, 비공개 원고, 승인 대화 식별자, 내부 검수 기록, 로컬 경로는 포함하지 않습니다. 일반적인 생성 출처 표시는 유지하되 민감한 메타데이터가 있으면 전송을 중단합니다. 확정본 공개 지시는 미승인 후보나 출전 번역문·외부 자산의 포괄적 재사용 허가가 아닙니다.

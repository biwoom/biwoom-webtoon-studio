---

이 파일은 프로젝트 로컬 절차이며 자동 등록되거나 실행되는 시스템 skill이라고 주장하지 않는다.
1. AGENTS, docs/workflow.md, 최신 continuity 원장을 읽는다.
2. `PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=src python3 -m biwoom_studio preflight ST-NNN`로 로컬 차단 항목을 확인한다. exit 2는 점검 실패가 아니라 아직 차단 상태임을 뜻한다.
3. 대화 승인과 로컬 파일 승인 기록을 대조한다. 파일 부재를 사용자 승인 거절로 해석하지 말고 미수입 상태로 보고한다.
4. 사용자 지시 변경의 영향 컷을 적고, 실제 시각 콘티·후보·대사 버전과 비교한다. 생성·재승인·예산을 임의 확장하지 않는다.
5. 실행 위임 시 허용 루트/명령, 입력 해시, 목표, 중지 조건, 예상 산출물, 승인 범위를 전달한다.
6. 결과 파일·해시·로그를 확인하고 미구현/미승인/보관 실패를 그대로 보고한다. 이 절차 자체는 명령 실행·유료 호출·공개 권한을 주지 않는다.
